# ProjectForge ⚡

AI-powered project generator for final-year students.

## Features
- AI-generated project ideas
- Cyberpunk UI with animations
- Secure API key handling
- Fully accessible

## Tech Stack
- Next.js 14, TypeScript, Tailwind CSS
- Google Gemini API
- Vercel (deployment)

## Live Demo
https://project-forge-gamma.vercel.app/

## Setup
1. Clone the repo
2. Copy `.env.example` to `.env.local`
3. Add your Gemini API key
4. Run `npm install && npm run dev`
