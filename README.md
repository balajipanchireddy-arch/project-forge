## 🎯 Overview

**ProjectForge** is an AI-powered platform that helps final-year students generate **complete, actionable project blueprints** based on their interests and skills. 

Instead of wasting hours searching for project ideas, students get a **guided, structured plan** with:
- ✅ A clear problem statement with "Why this matters" explanation
- ✅ 5-6 core features with plain-English explanations
- ✅ Recommended tech stack with reasoning
- ✅ 6-week development roadmap with guidance
- ✅ 3 improvement ideas for higher grades
- ✅ Save, Share, and Download functionality

---

## ✨ Features

### 🎨 **Clean White Professional UI**
- Glassmorphism design with subtle shadows
- Clean white background with high contrast
- Smooth animations and transitions
- Fully responsive on all devices
- Professional, academic-friendly design

### 🤖 **AI-Powered Generation**
- Powered by Google Gemini 3.6 Flash (FREE)
- Generates structured JSON output
- 5-10 second response time
- Real-world, academic-focused ideas

### 📖 **Guided Project Blueprint**
Each generated project includes:

| Section | What It Provides |
|---------|------------------|
| **Project Overview** | Title, difficulty level, team size, timeline |
| **Understanding the Problem** | Problem statement + "Why this matters" explanation |
| **Core Features** | 5-6 features with plain-English explanations |
| **Tech Stack** | Recommended technologies with reasoning |
| **Development Roadmap** | Week-by-week plan with "What to do" guidance |
| **Improvement Ideas** | 3 future upgrades with learning resources |
| **Next Steps** | Save, Share, Download buttons |

### 🔒 **Security**
- API keys stored securely in environment variables
- NOT exposed in code or GitHub
- Input validation using Zod
- Rate limiting (5 requests/hour)

### ♿ **Accessibility**
- Semantic HTML elements
- ARIA labels and roles
- Full keyboard navigation
- High contrast colors
- Loading states with announcements
- Focus indicators for keyboard users

### ⚡ **Performance**
- Progress bar with status messages during generation
- Spinner animation for loading states
- Smooth fade-in transitions
- Optimized API calls
